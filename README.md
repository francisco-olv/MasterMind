# 🧩 MasterMind Game

A modern, interactive web implementation of the classic **Mastermind** code-breaking game built with **Python**, **Streamlit**, and **Pytest**.

---

## 📖 About the Game

The objective of Mastermind is to guess a secret 4-letter code randomly generated by the system.

### 🎯 Rules & Mechanics:
- **Alphabet**: The secret code consists of **4 unique letters** chosen from **A** to **F**.
- **Attempts**: You have a maximum of **10 attempts** to break the code.
- **Feedback System**:
  - ⬛ **Black Match:** Correct letter in the correct position.
  - ⬜ **White Match:** Correct letter, but in the wrong position.
- **State Persistence**: Your attempt history and game state are saved across user interactions.

---

## 🛠️ Tech Stack & Concepts Applied

- **Python 3.10+**: Core business logic and modular validation.
- **Streamlit**: Web interface, custom session state management, and visual components.
- **Pytest**: Automated unit testing covering valid inputs, duplicate detection, boundary errors, and scoring algorithms.
- **Git & GitHub**: Structured feature branch workflow (`feature/*`) with Pull Request code reviews and standard commit conventions.

## 🚀 Getting Started

### Prerequisites
- Python 3.10 or higher installed.
- A virtual environment set up (recommended).

### Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/francisco-olv/MasterMind.git
   cd MasterMind
   ```
2. **Create and activate your virtual environment (WSL / Linux / macOS):**
    ```bash
    python3 -m venv .venv

    source .venv/bin/activate
    ```
3. **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
4. **Run the Streamlit application:**
    ```bash
    streamlit run app.py
    ```
5. **Run unit tests:**
    ```bash
    pytest
    ```
